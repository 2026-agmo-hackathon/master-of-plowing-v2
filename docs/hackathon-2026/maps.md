모든 좌표·수치는 맵 정의 파일(`simulator/public/maps/*.json`)과 시뮬레이터 소스에서 그대로 추출했습니다.

- 폴리곤 좌표는 전부 `[x, z]` 쌍

- 도랑(ditch)은 driveArea 경계 밖 0→−1.4 m→0 반사인 단면 — **바퀴가 빠지면 스스로 못 나옵니다** (`TerrainPrimitives.ts` `driveAreaWallHeight`, line 67). 둑(berm)은 같은 단면의 +방향(못 넘는 벽).
- leveling-basin(Rough Basin) 맵은 select box 에서 숨김 처리되어 대회 대상이 아닙니다 (`MapCatalog.ts:57` `HIDDEN_BUILTIN`).

## GPS 좌표 변환

월드 좌표 ↔ 위경도 변환 (`GeoOrigin.ts` line 55, `worldToLatLon`):

```
lat = origin.lat − z / 110540
lon = origin.lon + x / (111320 × cos(origin.lat))
```

- `METERS_PER_DEG_LAT = 110540` (`GeoOrigin.ts:32`), `METERS_PER_DEG_LON_EQUATOR = 111320` (`GeoOrigin.ts:35`)
- 이 상수는 **대회 리더보드(backend maps.js)와 동일한 식**입니다. 위도에 111320 을 쓰면 0.7% 오차로 채점 셀이 밀립니다 (`GeoOrigin.ts` 헤더 주석).
- 리더보드는 앱이 보낸 위경도를 역변환해 **0.5 m 채점 셀**로 집계합니다 (`GeoOrigin.ts:24` 주석).

## 커버리지(경작해야 할 면적) 채점 기준

### 채점 대상 면적

- 각 맵의 `workArea` 폴리곤(아래 맵별 좌표) 내부가 채점 대상입니다. 면적은 shoelace 공식으로 계산 (`PolygonUtils.ts:60` `polygonAreaM2`, `GameLoopV2.ts:236`).
- `driveArea` 는 주행 가능 한계 — 그 밖은 도랑/둑이라 물리적으로 나갈 수 없습니다.

### tilled 판정 방식 (시뮬레이터 내부)

- **그리드 해상도**: SoilGrid 셀 **0.2 m × 0.2 m** (셀 면적 0.04 m²) — `SoilGrid.ts:69` `DEFAULT_GRID.cellSize = 0.2`. 맵 크기(size.width × size.height)가 그대로 그리드 범위가 됩니다 (`useGameLoop.ts:146-148`; 대회 맵은 `cellSizeM` 미지정 → 기본 0.2 m).
- **경작도(0~1)**: 셀별로 쟁기 절삭 깊이를 실용 깊이 0.163 m 로 정규화해 최댓값 적립 — `SoilGrid.getTillRatio` (`SoilGrid.ts:853`), 적립 로직은 `ImplementSystem.ts` line 886~ ([terrain.md](./terrain.md) §6). plow 만 깊이 비례이고 그 외 작업기는 갈렸으면 1.
- **완료 판정**: 경작도 ≥ **0.999** 인 셀이 완료 — `modes/tillage.ts:20` `completionThreshold: 0.999`. 즉 절삭 깊이 ≥ 0.163 m × 0.999 ≈ **16.3 cm**.
- **진척률**: `completionRatio = (workArea 내 완료 셀 수) / (workArea 내 전체 셀 수)` — `RecSession.ts:298` `computeCompletionRatio`.
- workArea 판정은 셀 중심점의 point-in-polygon — `SoilGrid.ts:790~` `workAreaMask`, `SoilGrid.isWorkAreaCell` (line 804).
- 화면의 갈린 흙 표시(셰이더)는 시각화일 뿐이고, 채점·REC 집계는 전부 위 그리드 값 기준입니다.

### REC(작업 기록) 품질 집계

`RecSession.ts` `snapshot` (line 396) — 셀 수 × 경작도 가중 × 셀 면적(0.04 m²)으로 집계:

| 항목 | 의미 |
|---|---|
| `totalWorkedAreaM2` | 작업한 총면적 (workArea 내) |
| `outsideWorkedAreaM2` | workArea **밖**에서 작업한 면적 |
| `duplicateWorkedAreaM2` | 이미 완료(≥0.999)된 셀을 다시 간 면적 |
| `reworkedAreaM2` / `reworkedAreaTotalM2` | 후진 자국 재경작 관련 면적 (현재/누적) |
| `reverseWorkedAreaM2` | 후진 상태로 작업한 면적 |
| `completionRatio` | workArea 대비 완료율 0~1 |

## 맵별 상세

각 맵의 `spawn` 은 트랙터 시작 위치, `workArea` 는 채점 대상 구획(레드 아웃라인), `driveArea` 는 주행 가능 경계입니다.
좌표 원본: `simulator/public/maps/<id>.json`

> **시작 좌표 기준 = 뒷오른바퀴(RR).** `spawn.x/z` 는 차량 중심이 아니라 **뒷오른쪽 바퀴 접지점**의 월드 좌표입니다(2026-08-14 변경, `GameLoopV2.teleportWorld`). 어느 체급(대형/중형/소형)을 갈아타도 뒷오른바퀴가 정확히 이 좌표에 섭니다. 세 대회 맵 모두 **대형 트랙터(jd6155m) 4바퀴가 workArea(레드 아웃라인) 안**에 들도록 좌표·헤딩을 맞췄습니다.
