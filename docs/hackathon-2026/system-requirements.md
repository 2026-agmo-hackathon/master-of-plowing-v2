# 시스템 요구사양

SeamOSWorld(시뮬레이터 + 대시보드 + CCU 가상머신)를 참가자 PC 에서 돌리기 위한 기준.
최소사양은 실측 기준이다 — 아래 "최소" 열의 노트북(AMD Ryzen 7 5825U, RAM 8GB)에서
v1.4.0 전체 스택 구동·자동조향 주행을 실검증했다. 권장사양은 대략 그 2배급이다.

| 항목 | 최소 (실측 검증) | 권장 (최소의 약 2배급) |
|---|---|---|
| CPU | 8코어 최신 모바일급 (AMD Ryzen 7 5825U 동급 이상) | 최소 대비 성능 2배급 — 데스크탑 8코어 3GHz+ (Ryzen 7 데스크탑급), 또는 Apple Silicon (M1 이상) |
| RAM | 8GB (가용 5.6GB 실측) | 16GB 이상 |
| 저장장치 | NVMe SSD, 여유 20GB | NVMe SSD, 여유 40GB |
| GPU | 내장 GPU (AMD Radeon iGPU 실측) | 내장 GPU 이상 (외장 불필요) |
| OS | Ubuntu 22.04 이상 (apt), macOS (brew) | macOS Apple Silicon 또는 Ubuntu 데스크탑 |
| 네트워크 | 인터넷 연결 (설치·리더보드 제출) | 동일 |

## 최소사양에서의 체감 (실측)

- 전체 스택(시뮬레이터 3D + 대시보드 + CCU VM) 정상 구동, 자동조향 주행 가능.
- 앱 신호 주기가 기준 100ms 대비 110~140ms 로 흔들릴 수 있다 (CPU 여유에 따라).
- 배속은 낮은 배수 위주로 쓰는 것이 안전하다. 고배속은 CPU 가 따라가지 못하면
  화면이 툭툭 끊길 수 있다.
- RAM 8GB 에서는 다른 무거운 프로그램(브라우저 탭 다수 등)을 함께 띄우지 않는 것을
  권한다 — CCU 가상머신이 2.5~4GB 를 사용한다.

## 권장사양을 권하는 이유

- **Apple Silicon Mac**: CCU 가상머신이 네이티브 가상화로 돌아 가장 빠르다.
  앱 신호 주기도 기준값(100ms)에 정확히 붙는다.
- **x86 Ubuntu**: CCU 가상머신이 ARM 에뮬레이션으로 돌기 때문에 같은 급이라도
  Mac 보다 CPU 를 더 쓴다. 그래서 x86 은 코어 수·클럭이 높을수록 좋다.
